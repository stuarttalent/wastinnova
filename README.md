# WASTiNNOVA Africa — Corporate Website

Professional, modern corporate website for **WASTiNNOVA Africa (Zimbabwe)** with a governance-led, compliance-by-design tone.

## Tech stack

- React + TypeScript (Vite)
- Tailwind CSS
- React Router

## Local development

```bash
cd web
npm install
npm run dev
```

## Pages / routes

- `/` Home (includes Purpose & Value, Services, Compliance positioning, etc.)
- `/services`
- `/compliance`
- `/technology`
- `/technology/demo` (mock “Digital Audit Trail Demo” manifest view)
- `/contact`
